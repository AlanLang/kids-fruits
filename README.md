# 水果碰碰乐

适合 3 岁小朋友的手机网页水果配对小游戏。

- 首页点击「开始游戏」，进入铺满屏幕的游戏区。
- 图案叠成两层或三层，只有未被覆盖的图案可以点击；消掉上层才会显示下层。
- 点击两个相同图案，连线后消除，播放轻柔音效。
- 五个随机主题，共 54 种图案：水果、动物、交通工具、玩具和花园。
- 无限随机关卡：进入关卡或重玩时，随机选择新主题、图案和配对位置。
- 从 3 对、两层开始，逐步增加到最多 6 对、三层，此后继续随机出题。
- 每种图案恰好一对；生成时从可消除的位置反向分配配对，保证所有合法消除顺序都能完成。
- 没有倒计时和扣分，支持自动提示、手动提示和重玩。
- 内置 SVG 水果插画、系统 Emoji 图案与 Web Audio 音效，不需要外部素材或构建依赖。
- 支持手机竖屏、横屏、键盘操作与减少动画偏好。

## 本地运行

```sh
python3 -m http.server 8765
```

打开 http://localhost:8765 。手机与电脑连接同一 Wi-Fi 后，也可通过电脑的局域网地址访问。

## 部署到 Vercel

将仓库导入 Vercel，Framework Preset 选择 Other，无需构建命令，直接部署根目录即可。也可以在此目录执行：

```sh
npx vercel --prod
```

音效需要先点击按钮才能播放，具体播放行为取决于浏览器与设备的声音设置。
